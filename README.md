# zamzy-live

High-Performance Digital Engineering, SaaS & Custom Software Agency Platform for ZAMZY (Hitech City, Hyderabad).

## Tech Stack
- **Frontend**: HTML5, Vanilla Modern CSS3 (Dark Mode + Glassmorphism), JavaScript (Vanilla ES6+)
- **3D Orbital Engine**: Custom 3D CSS Matrix with dynamic pointer and touch inertial physics
- **AI Consultation**: DeepSeek-V3 AI Assistant with real-time lead onboarding & conversation transcript storage
- **Backend**: PHP 8+ / MySQL with auto-migration schema engine
- **Executive Admin Dashboard**: Inquiries, Demo Requests, Client Reviews, Careers & Freelance Guild, Chat Reports

## Setup & Deployment
1. Copy `.env.example` to `.env` and set your MySQL and DeepSeek API credentials.
2. Serve via Apache / PHP 8+ (e.g., XAMPP, Nginx, or Docker).
3. Access the live site at `http://localhost/zz/index.html` and Admin Dashboard at `http://localhost/zz/admin/`.
